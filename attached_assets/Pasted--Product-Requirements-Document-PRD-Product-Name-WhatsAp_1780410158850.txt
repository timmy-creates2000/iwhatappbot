# Product Requirements Document (PRD)

# Product Name

WhatsApp Community Growth Manager

# Version

MVP 1.0

# Overview

WhatsApp Community Growth Manager is a web application that connects to a user's WhatsApp account through Baileys and helps manage contacts, group additions, personalized outreach messages, and campaign tracking from a single dashboard.

The system is designed for business owners, tutors, community managers, creators, and marketers who want to manage WhatsApp communities efficiently.

The platform uses:

* Node.js
* Express.js
* Baileys
* React
* Tailwind CSS
* Turso Database
* Gemini API

---

# Problem Statement

Managing large numbers of WhatsApp contacts manually is time-consuming.

Users often need to:

* Import contacts
* Organize contacts
* Add contacts to groups
* Send personalized messages
* Monitor outreach performance

Current workflows require repetitive manual actions and lack centralized management.
